# 예매 흐름

## [booking-flow.overview] 예매 순서
keywords: 예매 순서 흐름 방법 과정 어떻게 절차 좌석 선택 결제
예매는 공연과 회차를 고르는 것에서 시작해요. 오픈 시각이 되면 대기열을 거쳐 입장하고, 매수를 정한 뒤 좌석을 골라 선택 완료를 눌러요. 좌석이 잡히면 결제 화면으로 넘어가 결제하고, 결제가 끝나면 예매가 확정돼 티켓 번호가 나와요. 확정된 예매는 내 예매에서 볼 수 있어요.

## [booking-flow.seat-taken] 다른 사람이 먼저 고른 좌석
keywords: 좌석 이미 선택 먼저 다른 사람 경쟁 충돌 다시 선택 실패 선점
같은 좌석을 여러 사람이 동시에 고르면 한 사람만 좌석을 잡아요. 다른 사람이 먼저 잡은 좌석을 고르면 이미 선택된 좌석이라고 안내해요. 이때는 줄을 다시 서지 않고 좌석만 다시 고르면 돼요.

## [booking-flow.confirm-pending] 결제 결과를 바로 알 수 없을 때
keywords: 확인 중 결제 결과 모름 지연 무응답 처리 중 기다림 상태
결제 결과를 바로 알 수 없으면 화면에 확인 중으로 보여요. 결제사에서 응답이 늦거나 오지 않은 경우예요. 결과가 확인되면 화면이 알아서 바뀌니 같은 결제를 다시 누르지 않아도 돼요. 오래 걸리면 내 예매에서 상태를 확인해 주세요.
