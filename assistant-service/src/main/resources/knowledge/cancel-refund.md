# 취소·환불

## [cancel-refund.user-cancel] 예매 취소
keywords: 취소 예매 취소 환불 신청 내 예매 취소하기 취소 방법 취소 수수료
사용자가 직접 예매를 취소하는 기능은 아직 준비 중이에요. 지금은 화면에서 확정된 예매를 취소할 수 없어요. 취소가 꼭 필요하면 고객센터에 문의해 주세요.

## [cancel-refund.auto-refund] 자동으로 환불되는 경우
keywords: 환불 언제 자동 환불 어떤 경우 돈 돌려받기 결제 금액 환불 기간
자동으로 환불되는 경우는 결제 가능 시간이 지난 뒤에 승인이 도착해 좌석이 이미 풀린 때예요. 이때 결제한 금액은 환불돼요. 결제가 거절된 경우에는 처음부터 결제가 되지 않아 환불할 금액이 없어요. 환불 상태는 내 예매에서 확인할 수 있어요.

## [cancel-refund.not-found] 환불이나 취소가 안 보일 때
keywords: 환불 안 됨 안 보여요 확인 어디서 내 예매 상태 문의 고객센터
환불이나 결제 상태는 내 예매에서 확인해 주세요. 상태가 계속 이상하면 고객센터에 예매한 공연, 회차, 결제 시각을 알려 주세요. 운영자가 결제 기록을 보고 확인해요.
