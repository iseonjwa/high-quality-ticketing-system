# 오픈 시각

## [open-time.when] 예매 오픈 시각
keywords: 오픈 시각 언제 몇 시 시작 예매하기 오픈 전 카운트다운 서버 시각
오픈 시각은 공연마다, 회차마다 달라요. 공연 상세의 회차 표에서 각 회차의 오픈 시각을 확인해 주세요. 오픈 전에는 예매하기 버튼이 비활성이고, 서버 시각을 기준으로 남은 시간이 보여요.

## [open-time.before-open] 오픈 전에 예매할 수 없어요
keywords: 오픈 전 미리 예매 일찍 접속 직접 호출 아직 오픈 전 새로고침
오픈 시각 전에는 예매를 시작할 수 없어요. 내 기기의 시계가 아니라 서버 시각으로 판단해서, 먼저 눌러도 열리지 않아요. 오픈 시각이 되면 공연 상세에서 예매하기를 다시 눌러 주세요.
