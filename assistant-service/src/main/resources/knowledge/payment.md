# 결제

## [payment.hold-time] 좌석을 잡은 뒤 결제
keywords: 결제 시간 선점 유지 제한 시간 남은 시간 만료 안 하면 좌석 풀림 반환
좌석을 잡으면 결제 화면에서 남은 시간이 보여요. 정해진 시간 안에 결제하지 않으면 좌석이 자동으로 풀려 다른 사람이 고를 수 있어요. 시간이 지났다면 좌석을 다시 골라야 해요.

## [payment.declined] 결제가 거절되면
keywords: 결제 거절 실패 카드 승인 안 됨 오류 거부 좌석 반환 다시 결제
결제가 거절되면 예매는 만들어지지 않고 잡았던 좌석도 풀려요. 카드 한도나 상태를 확인한 뒤 처음부터 다시 예매해 주세요. 거절된 결제로 돈이 빠져나가지 않아요.

## [payment.auto-refund] 시간이 지난 뒤 승인된 결제
keywords: 환불 자동 시간 지난 뒤 승인 만료 후 결제 돈 돌려 금액 늦게 승인
결제 가능 시간이 지난 뒤에 승인이 도착하면 좌석은 이미 풀린 상태예요. 이 경우 결제 금액은 자동으로 환불돼요. 좌석이 확정되지 않았으니 내 예매에서 상태를 확인해 주세요.

## [payment.unknown] 결제 상태를 확인하고 있을 때
keywords: 결제 확인 중 결제사 무응답 이중 결제 중복 다시 누르면 안 되나요 결과 모름
결제사 응답이 없으면 결제 결과를 결제사에 다시 물어 확인해요. 확인되는 동안은 결제 버튼을 반복해서 누르지 않아도 돼요. 같은 결제는 한 번만 처리되도록 막혀 있어요. 끝내 확인이 어려운 건은 운영자가 직접 확인해요.
