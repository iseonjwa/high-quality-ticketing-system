# 2026-11-01 hyoseung AI 판단 일지

- [지적] AI가 회차 좌석 생성 API(ISE-98)를 구현한 뒤 작성자 검토 없이 커밋·push·PR(#138)까지 진행했다. 구현 후에는 기능 흐름과 적용한 규칙을 설명하고 멈추며, 커밋·push는 작성자가 코드를 검증하고 지시한 뒤에만 하게 했다. 지시 밖의 행동은 먼저 허락을 받는다 — 근거: "push 올리는 건 내가 코드 검증한 후에 해라" "내가 하라는 거 외에 너가 하려는 건 허락을 맡고 해야지" (Claude Code)
- [수용] 공연 목록·상세 조회(ISE-99)에서 SA에 규칙이 없는 부분을 AI 제안대로 정했다. saleStatus는 오픈 전 BEFORE_OPEN, 오픈~공연 시작 전 ON_SALE, 시작 이후 CLOSED(매진 없음). nextStartsAt·nextOpenAt은 아직 시작하지 않은 가장 빠른 회차 값이고 없으면 null. 목록은 최근 등록 순. 없는·지운 공연은 404 — 근거: "내 질문에 답하고 4번까지 해줘봐" (Claude Code)
