# 2026-11-14 hyoseung AI 판단 일지

- [거부] 배포 측정을 다시 시작하면서 AI가 보낸 절차가 11/12 측정과 달랐다. 단계마다 하던 이미지·상한 설정 확인(docker inspect), 창 A의 CPU·메모리 기록 시작과 멈춤이 빠졌다. 사용자가 지금까지 한 방식과 다르다고 지적했고, AI는 11/12 세션 기록을 다시 읽어 단계마다 같은 다섯 동작(바꾸기, 확인, 기록 시작, 측정, 기록 멈춤)으로 맞췄다.
  - 근거: "지금까지 부하테스트 진행한 거랑 좀 다른 것 같아. 너 지금까지 어떻게 했는지 전부 확인하고 와" (Claude Code, 말투 다듬음)
- [거부] AI가 사용자가 붙여 준 진행 상황(창 B는 `git pull`까지, 연결 확인 curl은 줄이 잘려 실패, 창 A는 이미지·상한 확인까지)을 확인하지 않고 다음 절차를 처음부터 다시 보냈다. 붙여 준 출력으로 어디까지 됐는지 먼저 짚고 남은 것만 보내게 했다.
  - 근거: "내가 어디까지 진행했는지 확인도 안하고 말할래? 어디까지 진행됐는지 정확하게 확인하고 진행해" (Claude Code, 말투 다듬음)
- [거부] AI가 측정 단계마다 명령과 상한 값만 보내고 그 측정이 무엇을 확인하는지 말하지 않았다. 또 사용자가 처음 정한 목표(같은 조건에서 개선 전·1차·2차를 상한 적용 전과 후로 재고, 적정 상한 값을 찾아 팀에 공유)에서 개선 전·1차의 상한 64 측정을 사용자 확답 없이 뺐다. 측정마다 목적을 먼저 말하고, 뺀 단계는 다시 넣을지 사용자에게 묻게 했다.
  - 근거: "지금 테스트하고 있는 게 뭔지는 말해야하는 거 아니야? ... 애초에 내가 테스트 뭐 해야하는지 얘기한 거 알고있긴 한거야?" (Claude Code)
- [지적] 사용자는 필요 없는 측정을 다시 넣으라는 것이 아니라, 명령만 보내면 지금 무슨 작업인지 몰라 AI가 원하지 않는 작업을 해도 고칠 수 없다고 했다. 단계마다 무엇을 하는지 항상 먼저 말하게 했다. 개선 전·1차의 상한 64 측정은 빼는 것으로 정리됐다.
  - 근거: "필요없는 테스트까지 하라는 말이 아니라 지금 뭘 하고 있는건지는 얘기를 해야지. ... 항상 얘기해." (Claude Code)
- [지적] AI가 측정 결과를 숫자만 옮기고 정상인지 이상한지 판단하지 않은 채 다음 단계로 넘어갔다. 사용자가 결과의 이상 여부는 AI가 파악하고 넘어가야 한다고 했다. 상한 128 결과를 보고 성공 처리량이 64와 같다(초당 약 295건)는 점을 짚고, 설정이 실제로 바뀌었는지 확인한 뒤 진행하기로 했다.
  - 근거: "결과가 이상한지 정상인지는 니가 파악하고 넘어가야지." (Claude Code)
- [수용] 팀원들이 판단 기록과 학습 노트를 저장소에 올린 것을 보고, 사용자가 이상한 내용이 없다면 자기 기록도 올리기로 했다. AI는 욕설·팀원 비난·비밀값·IP를 점검하고 개인 공인 IP 예시를 문서용 주소로 바꾼 뒤 PR #614로 올렸다.
  - 근거: "팀원들도 학습기록이나 저 판단들 올렸다는데 나도 올려야하지 않나. 이상한 내용 없다고 한다면 올려야할듯" (Claude Code)
- [지적] ISE-270 판단 기록을 쓰며 AI가 ADR 0054(좌석 캐시를 서비스 메모리에 둠)의 근거를 "미기재"로 두자, 사용자가 이미 그 이유를 설명했었다고 짚고 다시 말해 줬다(역직렬화로 매 요청 15,000개 객체가 생겨 1차 개선의 의미가 줄고, 바뀌지 않는 값을 서버 한 대가 쓰므로 네트워크 비용·객체 생성이 없는 서비스 메모리를 골랐다). 근거 칸을 그 말로 채웠다 → [개별 기록](../2026-11-08-seat-layout-cache-memory-not-redis.md)
  - 근거: "나 분명히 얘기했었는데 ... 아무튼 지금이라도 알았으면 채워" (Claude Code)
