# AI의 Java 25 제안 대신 Java 21 선택

## 맥락

공통 모듈 개인 초안의 구현 계획을 검토했다. 기존 SA MASTER v3와 Codex 계획은 Java 25를 기준으로 했다.

## AI 제안

Java 25, Gradle 9, Spring Boot 4.1.x를 사용해 공통 모듈을 구현하고 프로젝트용 Java 25 환경을 준비한다.

## 판단

- 결과: 거부 (Java 25 선택에 한정)
- 판단자: Junhyun An
- 근거: 미기재
- 사용자 원문: "자바21버전으로 결정하자! SA도 수정하고"
- 검토한 대안: Java 25, Java 21

## 반영

[ADR 0001](../../decisions/0001-java-21.md), Notion SA 정본, [저장소 SA](../../core/SA%20MASTER.md) 9-1, Gradle과 CI에 Java 21을 반영한다. 팀 전체 합의로 표기하지 않는다.

## 검증

검증 결과는 [워크스페이스 가이드](../../guides/workspace.md)에 기록한다.

## 판단 이력

- 2026-10-26 거부: Java 25 제안 대신 Java 21을 선택하고 SA 수정 지시

## 발표·면접 포인트

AI의 버전 제안을 그대로 채택하지 않고 사용자가 개발 기준을 지정했다. 선택 이유는 대화에서 제시되지 않았다.
