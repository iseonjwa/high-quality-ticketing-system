## 반영

local 기본 바인딩과 JVM runner를 loopback으로 제한하고 Compose에는 내부 바인딩을 명시했다. 두 권한 필터는 Spring PathPattern을 사용한다. runner와 스모크는 Compose 환경변수 해석 결과를 공통으로 사용한다. 가입·로그인의 비밀번호 바이트 검사를 공유한다.

## 검증

수정 전 경로·인증 검사 10건과 비밀번호 경계 검사 2건이 실패했고 수정 후 통과했다. 최종 JUnit 45건·Python 9건, JVM 앱 7개 소켓 14개와 HTTP 39건, Compose HTTP 42건을 확인했다. [워크스페이스 가이드](../../guides/workspace.md)와 [TS-8~12](../../troubleshooting.md)에 명령과 결과를 남겼다.
