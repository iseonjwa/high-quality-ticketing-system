# 공통 코드 작성 규칙 7개 수용과 Note 주석 남발 금지

## 맥락

- 해결하려던 작업: 다른 세션에서 결정한 설계를 유지하면서 코드 가독성과 학습에 도움이 되는 공통 규칙을 보완한다.
- AI 활용 방식: 간결하고 읽기 쉬운 코드와 `Note:` 주석을 예로 들며 추가할 규칙을 추천해 달라고 요청했다.

## AI 제안

읽는 흐름, 메인 메서드의 업무 흐름, 의미와 단위가 드러나는 이름, 필요한 추상화와 기존 공통 계약, 이유·주의점을 설명하는 `Note:`, 실패 의미의 보존, 코드와 설명의 동시 갱신을 제안했다.
제안 맥락은 [학습 노트](../../learning/junhyun/qna/2026-10-27-common-coding-rules.md)에 있다.

## 판단

- 결과: 수용. 7개 규칙 전체를 반영하고 `Note:` 남발 금지 조건을 명시한다.
- 판단자: Junhyun An
- 사용자 원문: "응ㅇ 이거 전부 넣어줘! Notes 를 너무 과도하게 남발하지 말도록 하고!"
- 근거: 앞선 요청에서 코드를 간결하고 읽기 좋게 작성하고 학습에 도움이 되는 주석을 두고 싶다고 밝혔다. 수용 시에는 주석을 과도하게 쓰지 않도록 조건을 덧붙였다.
- 적용 범위: 저장소의 코드 작성·수정·리뷰 지침. 기존 코드에 주석을 일괄 추가하거나 포맷을 바꾸라는 요청으로 확대하지 않는다.

## 반영

- [코드 작성 가이드](../../guides/code-style.md)에 7개 규칙과 선택적인 `Note:` 기준을 둔다.
- [AGENTS.md](../../../AGENTS.md)에 핵심 원칙과 코드 작성·수정·리뷰 시 읽을 문서를 추가한다.
- [문서 지도](../../README.md)와 [문서 작성 가이드](../../guides/writing.md)에 정본 링크를 연결한다.
- 학습 노트의 추천안을 정본 가이드로 옮겨 중복된 규칙을 따로 관리하지 않는다.

## 검증

실행 코드는 변경하지 않았다. `bash script/records-check.sh`와 `git diff --check`가 통과했다. 기록 검사에는 기존 판단 6건의 근거 미기재 경고가 남아 있다.
변경 문서의 로컬 링크 82개와 코드 작성 시 필수 문서 연결, 7개 규칙 및 `Note:` 남발 방지 기준을 확인했다. 애플리케이션 빌드·실행 테스트 대상은 없다.

- 학습을 돕는 주석을 적용 지점에만 두고, 자세한 설명은 학습 노트·ADR로 연결해 정확성과 유지 비용을 함께 관리한다.
