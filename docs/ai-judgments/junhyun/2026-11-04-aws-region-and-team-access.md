# 배포용 AWS 계정 운영: 시드니 리전을 유지하고, 팀원은 각자 SSH 키와 IP로 접속하며 콘솔 초대는 필요한 사람만 함

## 맥락
- 해결하려던 작업: M3 배포(ISE-174·175)를 위해 만든 AWS 계정의 초기 설정. AI는 처음에 루트 MFA, 콘솔용 IAM 관리자 사용자, 서울 리전 고정 순서로 안내했다.
- 사용자가 IAM 사용자를 만들었는데 비밀번호 단계가 없었고, 사용자 화면에 콘솔 로그인 칸이 없었다. 화면 캡처를 받아 AI가 AWS 문서를 확인했다.

## AI 제안
- 이 계정은 AWS의 새 가입 방식(Sign up for AWS (new))이다. 루트 사용자가 없고 Builder ID가 소유하며, 관리형 SCP가 `iam:*LoginProfile*`을 거부해 IAM 사용자는 콘솔에 로그인할 수 없다. 처음 안내(루트 MFA, 콘솔용 IAM 관리자)는 예전 가입 방식 기준이라 맞지 않았다.
- 리전은 연락처 국가로 정해져 한국은 시드니(`ap-southeast-2`)로 고정된다. 서울을 쓰려면 Paid plan으로 올린 뒤 고급 기능을 활성화해야 하고, 이 활성화는 되돌릴 수 없으며 지출 한도가 사라진다.
- 추천: 시드니를 유지한다. ADR 0046과 `docs/design/infra/load-test.md`는 "같은 리전"만 정했으므로 배포 EC2, Jenkins EC2, 부하 발생기를 모두 시드니에 두면 설계와 어긋나지 않는다. 한국에서 시연 화면을 열 때만 응답이 서울보다 늦다.
- 대신할 설정: Builder ID(또는 가입에 쓴 Google·GitHub 계정)에 MFA를 걸고, 만든 IAM 사용자 `iseonjwa-admin`은 지운다.
- 팀원 접근(키 페어·보안 그룹을 만든 뒤 "팀원들은 어떻게 접속해?"에 대한 답): 서비스(8080)는 공개라 준비가 없다. 서버 SSH는 팀원마다 자기 키를 만들어 공개 키와 IP를 보내고, 계정 주인이 EC2를 만들 때 `authorized_keys`와 보안 그룹에 등록한다. 키 페어 `.pem`은 돌려 쓰지 않는다(한 명만 지우기, 누가 접속했는지 가리기). AWS 콘솔은 AWS Settings 팀원 초대로 주되, 초대받은 사람은 프로젝트 자원을 모두 다룰 수 있고 비용은 못 보므로 지금은 초대하지 않고 부하 발생기를 직접 띄울 사람이 생기면 그 사람만 초대한다.

## 판단
- 결과: 수용
- 판단자: Junhyun An
- 근거: 미기재. 리전은 "오케이 6단계부터 다시 알려줘"(서울 전환을 요청하지 않고 키 페어·보안 그룹 단계로 넘어감), 팀원 접근은 "좋아 요청했으면 나중에 추가하면 되는거지?"(팀원에게 공개 키와 IP를 요청했고 등록은 EC2를 만들 때 함)
- 검토한 대안: Paid plan 전환과 고급 기능 활성화로 서울 리전 사용(되돌릴 수 없고 지출 한도가 사라져 고르지 않음), 키 페어 하나를 팀이 같이 쓰기, 팀원 전원 콘솔 초대

## 반영
- 학습 노트 `docs/learning/junhyun/qna/2026-11-04-aws-account-initial-setup.md`를 두 가입 방식으로 나눠 다시 썼다.
- 학습 노트의 "팀원은 어떻게 접속하나" 절에 접속 세 층과 등록 절차를 적었다. 사용자가 팀원에게 공개 키와 IP를 요청했다.
- 배포 설계 문서(`docs/design/infra/deployment.md`, ADR 0044·0046)는 특정 리전을 적지 않아 고칠 곳이 없다. 실제 리전 이름은 배포 compose(ISE-174)·Jenkins(ISE-175) 구현 때 런북에 적는다.

## 검증
구현 전. 사용자가 AWS Settings의 프로젝트 정보에서 리전을 확인한다.

## 판단 이력
- 2026-11-04 수용: 시드니 유지, 서울 전환 안 함
- 2026-11-04 수용: 팀원 SSH는 각자 키와 IP, 콘솔 초대는 필요한 사람만

## 발표·면접 포인트
- 서버 접속 키를 사람마다 따로 두면 한 명을 빼거나 키가 샜을 때 그 줄만 지우면 되고 접속 기록도 사람별로 남는다.
- 클라우드 계정의 가입 방식이 리전과 권한 모델을 정해 버릴 수 있다. 설계를 "같은 리전"처럼 리전 이름에 묶지 않고 써 둔 덕분에 리전이 바뀌어도 설계를 고치지 않았다.
