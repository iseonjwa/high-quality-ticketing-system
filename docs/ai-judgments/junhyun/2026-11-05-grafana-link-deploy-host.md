# 시연 모드 Grafana 링크를 localhost:3000에 고정한 AI 설계를 거두고, 배포 서버 Grafana를 팀원 IP로 열어 화면을 연 호스트 기준으로 잇게 함

## 맥락
- 해결하려던 작업: 배포 서버에서 시연 모드(`?demo=on`, ISE-180)의 traceId를 눌러 Grafana "요청 로그" 대시보드로 가기.
- 사용자가 11/5 첫 자동 배포(#338) 뒤 배포 서버에서 시연 모드를 켜고 링크를 눌렀는데 `localhost`로 연결됐다.
- AI 활용 방식: 사용자가 "배포 상황에서는 해당 네트워크의 grafana 주소를 가리켜야 해! 관련 설정이 하드코딩 되어있나본데?"라고 지적했다.

## AI 제안
- **원래 설계(ISE-180)**
  - 링크 기본 주소는 `http://localhost:3000`이고, 빌드 변수 `VITE_GRAFANA_URL`로만 바꾼다.
  - 배포 서버 Grafana는 `127.0.0.1:3000`에만 묶여 있으므로, 발표자 노트북이 SSH 터널로 Grafana를 3000에 연다는 전제였다.
  - 배포 이미지는 빌드 인자 없이 이 기본값을 쓴다(`frontend/Dockerfile`).
- **지적을 받은 뒤 AI가 낸 선택지**
  - Grafana 공개 방식: ① 3000을 팀원 IP에만 열고 링크를 화면을 연 호스트 기준으로 만든다(추천) ② nginx 80 아래 `/grafana/`로 합친다 ③ SSH 터널을 유지한다.
  - 로그인: ① 배포 서버에서만 익명 보기(Viewer)를 켠다(추천) ② admin 로그인을 유지한다.
  - 반영 시점: 리허설(11/6) 전(추천) 또는 리허설 뒤.
- 함께 받은 질문 두 가지
  - "외부에서 IP로 프론트 접속이 안 된다던데?"
    - 서버를 확인하니 80은 전체에 열려 있었다. 15:00~15:28에 외부 IP 세 곳이 정상으로 받았다.
    - 원인 후보로 지출 한도 정지 기간, https로 연 경우, 배포 중 잠깐을 제시했다.
  - "https 무료로 달아주는 서비스 없나?"
    - Let's Encrypt IP 인증서(2026-01-15 정식, 약 6일)를 추천했다.
    - 리허설 전날 바꾸는 위험을 들어 시점을 물었다.

## 판단
- 결과: 거부(원래 설계). 대안은 AI 추천을 모두 골랐다.
- 판단자: Junhyun An
- 근거: "배포 상황에서는 해당 네트워크의 grafana 주소를 가리켜야해!"
- 고른 것
  - 3000을 팀원 IP에만 열기
  - 익명 보기(Viewer) 켜기
  - 리허설 전에 반영
  - HTTPS는 리허설 뒤에 따로
- 검토한 대안
  - nginx `/grafana/` 하위 경로: 80이 전체에 열려 있어 IP 제한을 nginx에 따로 둬야 한다.
  - SSH 터널 유지: 시연하는 사람마다 터널을 먼저 열어야 한다.
  - admin 로그인 유지: HTTP라 비밀번호가 평문으로 오간다.

## 반영
- 브랜치 `fix/ISE-180-grafana-link-deploy-host`
  - 프론트: 기본 주소를 `화면을 연 호스트:3000`으로 바꾼다.
  - `compose.deploy.yml`: Grafana를 `3000:3000`으로 열고 익명 Viewer를 켠다.
  - 문서: 배포·프론트·관측 설계와 팀원 안내 문서를 맞춘다.
- 보안 그룹 3000 규칙(팀원 IP)은 사용자가 콘솔에서 넣는다. 저장소에는 IP를 적지 않는다.
- 이 결정으로 11/4부터 대기 중이던 "관리 화면 IP 접근"도 정해졌다. Grafana만 팀원 IP로 열고, 나머지는 SSH 터널이다.

## 검증
구현 중. 반영 뒤 확인할 것은 다음과 같다.
- 팀원 IP에서 `http://52.63.10.174:3000`이 열리고, 허용되지 않은 IP에서는 막힌다.
- 시연 모드 traceId 링크가 로그인 없이 대시보드를 연다.
- 익명 사용자는 대시보드를 고칠 수 없다.

## 판단 이력
- 2026-11-05 거부: localhost 고정 링크 설계를 거두고 대안 세 가지를 골랐다. HTTPS는 리허설 뒤로 미뤘다.

## 발표·면접 포인트
- 시연 도구도 배포 환경에서 실제로 눌러 봐야 한다. 로컬 전제(localhost, SSH 터널)가 배포에서 깨지는 것을 첫 배포 직후에 찾았다.
- 관리 화면은 "로그인 있는 화면 하나 + IP 제한"으로 공개 범위를 좁혔다. 익명 보기는 IP 제한이 있을 때만 켰다.
