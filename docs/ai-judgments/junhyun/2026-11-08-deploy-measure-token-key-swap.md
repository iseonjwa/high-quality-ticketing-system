# 배포 환경 부하 측정 기반(ISE-191)을 M4로 두되 측정 전에 끝내고, 측정용 토큰은 측정 동안만 측정 전용 키로 바꿔 띄우기로 함

## 맥락
- 해결하려던 작업
  - Linear 남은 이슈를 정리하다가 ISE-202(대기열 측정, 권영은, M3)가 ISE-191(배포 측정 기반, 안준현, M4, 손대지 않음)을 기다리는 것을 찾았다.
  - 팀원이 ISE-191을 M4에서 할지 정해 달라고 했다.
- AI 활용 방식: Claude Code에게 열린 이슈 46개와 PR, 코드를 대조해 현재 상황과 정리 계획을 요청했다.

## AI 제안
- ISE-191은 M4에서 한다. 다만 배포 서버가 다시 켜져 측정이 시작되기 전에 끝낸다. 그렇지 않으면 팀원의 배포 측정이 모두 밀린다.
- 항목별 방식
  1. **측정용 토큰**
     - 측정하는 동안만 서버 `.env`의 Access·입장 토큰 키를 측정 전용 키로 바꿔 띄운다.
     - k6가 그 키로 토큰을 직접 서명한다.
     - 측정이 끝나면 운영 키로 되돌린다. 그동안 기존 로그인은 끊긴다.
     - ADR 0046의 "운영 키를 측정 도구에 넣는 위험"에 대한 대안으로 적는다.
  2. Prometheus remote write 수신을 켠다. 9090은 발생기 보안 그룹에서만 연다.
  3. 추적 샘플링은 측정 전용 compose 덮어쓰기로 0.01로 낮춘다.
  4. Mock PG 장애는 서버 안에서 curl로 건다. 포트는 열지 않는다. ISE-71은 여기에 합친다.
  5. Mock PG 기준 지연은 300ms다.
  6. 기록 도구는 `docker exec`로 쓰는 절차를 README에 적는다.
  7. 발생기 EC2는 계정 주인이 측정 날 만든다.
- 검토한 대안: 측정 전에 가입·로그인·대기열을 거쳐 토큰을 미리 받아 두는 도구(ISE-201).
  - 서명 키가 필요 없다는 장점이 있다.
  - 하지만 입장 토큰 10분 만료와 초당 입장 50명 제한 때문에 대규모 인원을 준비하기 어렵다.
  - 권영은이 1번 방식을 전제로 ISE-201을 취소해 두었다.

## 반영
- 브랜치 `feat/ISE-191-deploy-loadtest-base`
  - 측정 모드 스크립트 `script/loadtest/measure-mode.sh`
  - 측정 덮어쓰기 `loadtest/deploy/compose.measure.yml`
  - k6 remote write 출력
  - 문서(`load-test.md`, `open-peak-load-plan.md`, ADR 0046 변경)
- 같은 브랜치에 ISE-193(배포 앱 G1 명시)도 넣는다. 팀원 측정 조건(배포 메모리 + G1)과 맞추려는 것이다.

## 검증
- 로컬 확인(2026-11-08, Sonnet 작업자 구현 뒤 메인 세션이 diff 확인)
  - compose 합치기: 측정 덮어쓰기에서 샘플링 0.01(앱 5개), Prometheus 수신 플래그와 9090, gateway·user-service·reservation-service의 서명 키가 `.env.measure` 값으로 바뀐다. 다른 설정은 그대로다.
  - remote write: 같은 digest의 Prometheus를 수신 플래그로 띄우고 `run.sh`에 `PROM_RW_URL`을 주자 `k6_iterations_total{testid=...}`가 조회됐다.
  - `measure-mode.sh`: `DRY_RUN=1`로 `.env.measure` 권한 600, 다시 실행해도 값 유지, 값 미출력, `off`·`status` 경로를 확인했다.
- 실제 서버의 측정 모드 켜고 끄기와 보안 그룹을 거친 remote write는 11/9 측정 때 확인한다.

## 판단 이력
- 2026-11-08 수용: ISE-191은 M4, 측정 전 완료, 측정 동안만 측정 전용 키

## 발표·면접 포인트
- 배포 환경 부하 측정에서 토큰을 어떻게 만들지는 보안과 측정 규모 사이의 교환이었다.
  - 운영 키를 발생기에 두지 않으려고, 측정 동안만 버리는 키로 바꿔 띄우고 끝나면 되돌렸다.
  - 대가는 그동안 기존 로그인이 끊긴다는 것이다.
