# 남은 백로그 설계안 중 AI 상담은 Claude API 키를 받아 Haiku 5.5로 시작하고, 토스 테스트 키는 수요일에 받고, 시연 장애 버튼은 Gateway 운영자 경로로 두기로 함

## 맥락
- 2026-11-09 사용자가 "지금 바로 시작할 수 있는 이슈를 다 끝내고, 설계가 필요하면 설계부터 하자"고 했다.
- 설계 에이전트들이 ISE-126(AI 상담), ISE-45·125(토스 결제)를 포함한 설계안을 냈다. 메인 세션이 결정이 필요한 점을 골라 물었다.

## AI 제안
- ISE-126(SA F8 내부 AI 상담, 발제 RAG 도전 과제)
  - 새 모듈 `assistant-service`를 둔다. 규정 문서를 키워드로 검색하고, Claude citations로 출처를 붙여 답한다.
  - 키가 없거나 장애가 나면 검색 결과만 주는 모드로 강등한다.
  - 상담 경로만 Gateway 시한을 10초로 둔다(ADR 필요).
  - 추천: Anthropic API 키를 받고 Haiku 5.5로 시작한다. 질문당 약 $0.0005이고, 모델은 설정값이라 나중에 바꿀 수 있다.
- ISE-45·125(토스)
  - API 개별 연동 테스트 키(`test_ck`/`test_sk`)가 필요하다. 결제위젯 키(`gsk`)로는 주문 조회가 안 돼 재확인 흐름에 못 쓴다.
  - 추천: 사용자가 오늘 개발자센터에 가입해 받는다.
- ISE-134(시연 장애 버튼)
  - 배포 서버 Mock PG는 이미 `loadtest` 프로필이라 장애 주입 API가 열려 있고, compose 내부에서만 닿는다.
  - 추천: Gateway에 운영자 전용 경로 `/api/v1/admin/demo/pg/**` → mock-pg를 둔다. Gateway가 이미 `/api/v1/admin/**`에 ADMIN 권한을 검사한다. 대안인 프론트 nginx 직접 중계는 인증이 없어 공개 시연 사이트에서 누구나 장애를 걸 수 있다.

## 판단
- ISE-126: 추천대로 키를 받고 Haiku 5.5로 시작한다(수용).
- 토스 키: 오늘이 아니라 수요일(11/11)에 가입해서 받는다(부분 수용).
- ISE-134: 추천대로 Gateway 운영자 전용 경로로 한다(수용).
- 이유는 따로 말하지 않았다. 오늘(11/9)은 배포 서버 측정(ISE-191·193·202)이 있는 날이다.

## 반영
- ISE-126: 설계안의 커밋 순서대로 진행한다. 키를 받기 전에는 검색 모드까지 먼저 만든다. 키는 개인 `.env`와 EC2 `.env`에만 두고 커밋하지 않는다.
- ISE-45: 수요일 전까지 가짜 토스 서버(JDK HttpServer)로 어댑터와 공통 계약 테스트를 먼저 만든다. 실제 토스 결제창 확인(ISE-125)은 키를 받은 뒤 한다.

- ISE-134: Gateway 라우트는 공유 설정이라 contract 이슈를 올리고 팀에 알린다. 서킷 브레이커 OPEN과 선점 만료 뒤 승인 환불은 버튼 한 번으로 재현되지 않아 k6 짧은 실행·Grafana와 테스트 결과로 보인다.

## 검증
- 아직 없다. 구현 PR에서 채운다.

## 판단 이력
- 2026-11-09: 위 두 가지를 정함. ISE-169는 설명을 들은 뒤 원안 거부·B로 정함(별도 기록 2026-11-09-ise169-reject-retry-takeover.md). ISE-134는 이어서 Gateway 운영자 경로로 정함.

## 발표·면접 포인트
