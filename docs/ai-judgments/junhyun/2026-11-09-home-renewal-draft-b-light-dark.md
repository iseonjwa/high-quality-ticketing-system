# 홈 리뉴얼 시안 3종 중 AI 추천(A 배치 + C 로고) 대신 시안 B와 B 로고를 고르고, 라이트·다크 두 모드와 굵기·카드 비율 수정을 요청함

## 맥락
- 해결하려던 작업: 프론트 디자인·성능 리뉴얼. 사용자가 메인 화면에 티켓 모양 카드, 샘플 광고, 새 로고를 넣은 시안 여러 개를 요청했다.
- AI 활용 방식: Claude Code가 Design 캔버스에 홈 시안 3종과 로고·광고 자리 비교판을 그렸다. 포스터는 저장소 그림(`frontend/src/assets/concert-art/`)을 썼고, 공연·광고주 이름은 지어냈다. 캔버스: https://claude.ai/artifact/8VBu6dCnSKQoJ2WzFrAhhZ (비공개)

## AI 제안
- 시안 A 티켓 부스: 밝은 화면, 지금의 인디고 유지, 대표 배너 전체가 큰 티켓, 가로 배너 광고와 목록 안 광고 카드.
- 시안 B 나이트 스테이지: 화면 전체가 어두운 공연장 톤, 그림을 꽉 채운 배너와 오픈 카운트다운, 화면 폭 전체 광고 띠와 목록 안 광고 카드.
- 시안 C 좌석표 그리드: 흰 바탕에 좌석 등급 색, 배너 옆 좌석 배치 그림, 맨 위 텍스트 광고와 오른쪽 세로 광고.
- 로고 3종: A 티켓 절취선 + 좌석 + 빨간 점, B 조명이 비춘 빨간 좌석(LIVE 배지 포함), C 아홉 칸 좌석 중 한 칸만 빨강.
- 추천: A 배치 + C 로고. 이유는 다른 밝은 화면과 이어지고, C 로고가 16px에서도 형태가 살아 있어서다. B는 홈만 어두워져 다른 화면과 따로 논다고 봤다.

## 판단
- 결과: 부분 수용(시안 하나를 골랐지만 AI 추천 조합은 고르지 않고 고칠 점을 더함)
- 판단자: Junhyun An
- 근거: "굵은 글씨가 너무 굵음 -> 한단계 굵기 낮추기. 얇은 글씨들은 괜찮음. 시안 B가 괭찮아보임. 이걸로 라이트모드, 다크모드 전부 만드러주고, 지금 예매 중 카드 들이 위아래로 너무 길어서 적당한 비율로줄여줘", "로고는 조명이 비춘 내 자리 괜찮은데 Live 배지만 삭제해줘"
- 검토한 대안: 시안 A(AI 추천 배치), 시안 C, 로고 A·C, 지금 로고 유지

## 반영
- 캔버스 2차(같은 링크): 시안 B를 다크·라이트 두 판으로 다시 그렸다.
  - 굵은 글씨는 한 단계씩 낮췄다(900→800, 800→700, 700→600, 600→500). 보통 굵기(400) 글씨는 그대로다.
  - 색은 두 모드가 같은 이름의 변수를 쓰게 했다. 구현 때 `:root`와 다크 변수 묶음으로 옮기기 위해서다.
  - '지금 예매 중' 카드는 포스터를 3:4에서 1:1로 잘라 카드 전체 비율을 약 4:5로 줄였다.
  - 로고는 B의 LIVE 배지를 뺐다.
  - 1차 A·C는 캔버스 아래로 옮겨 남겼다.
- 화면 모드(2026-11-09 사용자 선택, AI 추천 1번 수용): 처음에는 운영체제 설정(`prefers-color-scheme`)을 따르고, 헤더의 전환 버튼으로 바꾼 값은 그 브라우저에 기억한다. 검토한 대안은 운영체제 설정만 따르기(2번)와 버튼으로만 바꾸기(3번, 기본 라이트)였다.
- 구현 때 바꿀 문서: 디자인 시스템 9절 4번 "다크 모드는 하지 않는다"(2026-11-02)를 위 방식으로 바꾼다. 로고 결정(9절 1번, 10절 로고 행)도 함께 고친다. 구현 PR에서 `docs/design/frontend/design-system.md`에 반영한다.
- 카드 높이: 2차에서 카드를 줄였다고 보고했지만 실제로는 줄지 않았다. 사용자가 지적해 고쳤다([기록](2026-11-09-home-card-shorten-not-applied.md)).

## 검증
- 시안: 캔버스는 화면 캡처로 따로 확인하지 않았다. 카드 높이는 사용자 지적 뒤 로컬에서 쟀다.
- ISE-208(라이트·다크 기반, 로고·파비콘, 굵기): 목 서버와 headless Chrome으로 1440px 홈·로그인·`/_design`·마이페이지와 360px 홈(로그인 전후)을 두 모드로 캡처해 확인했다. 프론트 테스트 1166개 통과.

## 판단 이력
- 2026-11-09 부분 수용: 시안 B와 B 로고(LIVE 배지 제외)를 고르고, 라이트·다크 두 모드, 굵기 한 단계 낮춤, 예매 중 카드 비율 축소를 요청
- 2026-11-09 수용: 화면 모드는 AI 추천 1번(운영체제 설정을 따르고, 전환 버튼 값은 브라우저에 기억)으로 정함. 근거: "화면모드는 1번으로!"
- 2026-11-09 수용: 다른 화면 시안 7종(공연 상세·대기열·좌석·결제·예매 완료·내 예매·추첨)을 그대로 확정했다. 다크 모드의 고른 좌석은 흰 좌석 + 검은 체크로 바꾼다(디자인 시스템 9절 3번 "검정 + 체크 + 인디고 고리"의 다크 판). 시안을 그리지 않은 로그인·내 정보·운영자 화면은 구현할 때 같은 색 변수로 맞춘다. 근거: "ㅇㅇ 이대로 가도 되겠다. 큰 수정은 아닌 것 같네 진행해줘"
