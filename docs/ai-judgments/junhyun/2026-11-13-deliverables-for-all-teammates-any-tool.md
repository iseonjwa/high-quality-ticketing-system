# 팀원 지시문이 Claude Code 세션만 전제했다는 지적으로, 필수 산출물 작업을 팀원 모두가 도구와 상관없이 돌리게 바꿈

## 맥락
- 해결하려던 작업: 발제 필수 산출물 중 빈 것(Synthetic Data 비교, 발제 기준선 표, 보상·Kafka-UI 캡처, 대표 사례 확인, 판단 기록 보강)을 팀원에게 넘기는 일.
- AI 활용 방식: Claude Code가 PR #580·#583과 이슈 ISE-264·265를 만든 뒤, 팀원별 지시문을 세션 스크래치 파일에 썼다.

## AI 제안
권우·강민·영은·효승에게 한 건씩 맡기는 지시문을 만들었다. 지시문은 모두 저장소를 직접 읽고 명령을 실행하는 CLI 에이전트 세션을 전제했다(`gh`, 저장소 경로, 스크립트). 리뷰 스크립트도 Claude Code CLI만 지원했다.

## 판단
- 결과: 거부(넘기는 방식)
- 판단자: Junhyun An
- 근거: "비어있는 필수 산출물은 팀원들 모두가 돌려야하는 거아냐? 팀원들은 클로드채팅세션만 쓰고있을 수도 있고, cli만 쓸수도 있음!"
- 검토한 대안: 없음

## 반영
- `docs/presentation/required-deliverables.md`: 발제 필수 산출물 전체를 표로 점검하고(상태, 위치, 남은 일, 영역 기준 제안 담당), 작업 키트 K1~K7마다 터미널 명령, CLI 지시문, Claude 채팅 지시문과 첨부 파일 목록을 붙였다. 채팅은 저장소를 못 읽고 명령을 실행하지 못한다는 전제로 썼다.
- `script/ai-review.sh`에 `--engine codex`를 더했다. 채팅용 방법(PR `.diff`와 프롬프트 파일 첨부)은 가이드 7-1·8절과 K7에 적었다.
- 사용자 지시로 남은 일을 모두 Linear 이슈로 올리고 담당자를 언급했다(마일스톤 M4 역할 기준 제안): 팀원별 ISE-266(권우)·268(영은)·269(강민)·270(효승)·272(준현), 산출물별 ISE-264(영은)·265(권우)·267(효승), 팀 결정 ISE-271(모두 언급). Linear 언급은 GitHub 동기화 이슈에서 `@<!-- -->이름`으로 바뀌어 GitHub 알림은 가지 않고, 담당자 배정만 연결된 GitHub 계정으로 간다.
- 점검 중 새로 찾은 빈 곳: SA 14장 AI 설계 검증 로그에 발제 양식의 "AI 프롬프트(요약)" 열이 없음, README에 접속 주소가 없음(워크스페이스 가이드에만 있음), RAG 테스트 질문 5개·정확도 평가 미확인.

## 검증
- `script/ai-review.sh 577 --engine codex`: 55초, 결과 파일 생성, 임시 worktree 정리 확인. Claude 두 번이 짚은 결함은 짚지 않고 다른 불일치를 "확인 필요"로 냈다.
- 채팅 지시문은 실제 채팅 세션에서 돌려 보지 않았다(미확인).

## 판단 이력
- 2026-11-13 거부: 특정 팀원·특정 도구를 전제한 넘김 대신, 팀원 모두가 어느 도구로든 돌릴 수 있는 점검표와 키트로 바꿈

## 발표·면접 포인트
- AI에게 일을 넘길 때 받는 사람의 도구(채팅, CLI, 터미널)에 따라 지시문이 달라야 한다. 채팅에는 파일을 첨부하고, 결과는 사람이 저장소에 올린다.
