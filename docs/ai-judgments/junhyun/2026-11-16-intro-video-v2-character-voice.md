# 소개 영상 v2에서 하린을 화면에 세우고 목소리를 다시 고르고, 실제 동작과 다른 결제 장면 내레이션을 바로잡음

## 맥락
- 해결하려던 작업: 11/14에 만든 92초 소개 영상(PR #618)을 다시 만든다. 준현은 실제 화면 녹화는 좋았지만, 주인공 하린이 목소리로만 나오고 목소리도 부자연스럽다고 봤다.
- AI 활용 방식: AI가 콘티 v2 초안을 Claude Docs 문서("빅빵 편 소개 영상 콘티 v2")로 올리고, 준현이 문서를 직접 고쳤다. AI는 codex로 하린 인물 시트와 장면 키 비주얼을 만들고, VoiceStudio로 하린·내레이터 목소리 후보를 세 개씩 만들어 비교 페이지로 들려줬다.

## AI 제안
- 콘티: 하린이 9장면 모두에 나오고, 실제 예매 화면 녹화는 하린의 폰 화면으로 보여 준다.
- 하린 그림: 웹툰·일러스트풍(추천), 실사풍, 말하는 아바타 중 고른다.
- 목소리: 하린은 사람이 녹음, 내레이션은 상용 음성 합성을 권했다. 로컬 VoiceStudio를 쓰기로 한 뒤에는 v1과 다른 설정(방송용 압축 없음, 품질 단계 48, 억양 변화)으로 하린 H1~H3, 내레이터 N1~N3 후보를 냈다.
- 장면 6: 준현이 고친 내레이션 "좌석이 잡혀 있는 동안 다시 결제할 수 있고"는 카드 거절 때의 실제 동작(선택한 좌석을 바로 해제)과 다르다고 짚었다. 장면을 "결제사 연결 불안정"(좌석 유지, 다시 결제)으로 바꾸는 A안을 추천했다.

## 판단
- 결과: 부분 수용
- 판단자: 준현
- 근거:
  - 콘티는 문서에서 직접 고쳤다. 내레이션 문장, 회상·공연 날 장면, 예매 완료 QR에서 부적이 튀어나오는 10번째 장면을 더했고, 모션그래픽 캐릭터 영상(긴장과 이완, 스쿼시 앤 스트레치)으로 만들라고 했다.
  - 하린 그림은 추천대로 웹툰·일러스트풍으로 하고, codex 특유의 자글거림을 없애는 프롬프트를 넣으라고 했다. 키 비주얼 8장을 받고 응원봉만 왕관 모양으로 바꿨다.
  - 목소리는 AI 추천(사람 녹음·상용 합성)을 받지 않고 로컬 VoiceStudio로 정했다. 후보 중 하린 H2(젊은 여성, 높은 목소리)와 내레이터 N1(중년 여성, 낮은 목소리)을 고르고 "N1은 조금 빠르게, H2는 두 문장 사이 간격을 더"라고 했다.
  - 장면 6은 A안으로 바꿨다("장면 A로 바꾸자").
- 검토한 대안: 실사풍·아바타 하린, 사람 녹음, 카드 거절 장면을 유지하고 내레이션을 "좌석은 바로 반환되고 돈은 한 번만 움직입니다"로 고치는 B안

## 반영
- 콘티 문서: Claude Docs "빅빵 편 소개 영상 콘티 v2"(비공개, 키 비주얼 8장 포함)
- 영상: `docs/presentation/demo/2026-11-16-intro-video-v2.mp4`(75초), 원본 `docs/presentation/demo/2026-11-16-intro-video-v2/`
- 목소리: 하린은 H2, 내레이터는 N1을 속도 1.0으로 다시 만든 것을 참조로 삼아 대사 14줄을 복제 생성한다. 하린의 두 문장은 서로 다른 장면에 나와 사이가 벌어진다.

## 검증
- 받아쓰기(whisper large-v3-turbo)로 대사가 쓴 대로 나오는지 본다. N1을 새로 설계했을 때는 "이선좌"가 "이선자"로 들렸고, N1을 참조로 복제하자 "이선좌"로 들렸다.
- 장면 6의 실제 동작은 목 모드 녹화로 확인했다. 결제사 연결이 불안정하면 "결제사 연결이 원활하지 않습니다 / 좌석은 남은 시간 동안 유지됩니다. 잠시 후 다시 결제해주세요."가 뜬다.
- 목소리가 자연스러운지는 준현이 듣고 골랐다. AI는 소리를 들을 수 없다.

## 판단 이력
- 2026-11-16 부분 수용: 하린 등장 콘티, 웹툰풍 하린, VoiceStudio H2·N1, 장면 6을 결제사 연결 불안정으로
- 2026-11-16 거부: AI의 첫 조립본(99초)은 대사 사이 간격이 길고(최대 6.5초), 숫자 장면에서 하린이 숫자를 가리고, 탭 장면에서 손가락이 폰 화면 뒤로 들어가고, 폭죽 삼각형이 뒤집혀 있었다. 준현이 짚어 대사 간격을 0.3~0.6초로 줄여 74.6초로 다시 맞추고, 하린을 옮기고, 손가락 자리를 화면에서 오려 내고, 폭죽을 줄무늬 원뿔로 다시 그렸다. 배경음악은 "알아서 무료 음원"이라 AI가 로그인 없이 받는 Kevin MacLeod "Life of Riley"(CC BY 4.0)를 고르고 엔드카드에 출처를 적었다
- 2026-11-16 수용: 다시 맞춘 75초 렌더본(mp4)을 보고 "반영해서 올려줘"로 받아, ISE-280 PR #618에 올렸다
- 2026-11-16 거부: AI가 영상 v2에서 "하린의 폰 화면" 구성을 잡으며 녹화를 모바일 크기로 바꾸고, 그 모바일 화면을 발표 자료 시안에도 그대로 써서 서비스를 모바일 앱처럼 보였다. 준현이 "우리 웹서비스야"라고 바로잡았다. 발표 자료 시안은 데스크톱 브라우저 창의 웹 화면으로 바꿨다(영상은 다음에 정한다)
- 2026-11-16 부분 수용: 영상도 웹 서비스로 보이게 다시 만들기로 했다. 대기열·좌석·결제·추첨 전날 밤·부적 장면의 녹화를 데스크톱 크기로 바꿔 브라우저 창 틀에 넣고, 오픈 직전·작년·이선좌 등장 장면은 codex로 노트북 앞 하린을 다시 그렸다. 강의실에서 폰으로 당첨을 확인하는 장면은 폰을 그대로 둔다("강의실 장면은 폰 쓰는거 그대로 하고, 나머지만 데스크톱 화면으로"). 공연 날 입장 티켓도 실제로 폰을 쓰는 장면이라 폰으로 두었다
- 2026-11-16 수용: 데스크톱으로 다시 만든 렌더본을 보고 "잘했구만!"으로 받아, 같은 PR(#618)에 한 커밋으로 올렸다
