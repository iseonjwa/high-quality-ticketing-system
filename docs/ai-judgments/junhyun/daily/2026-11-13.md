# 2026-11-13 junhyun AI 판단 일지

- [부분 수용] AI는 ISE-262에서 Synthetic Data 도구와 데이터를 만든 뒤 배포 서버에서 균일 O1·Synthetic O1·A0를 바로 재려고 측정 순서까지 준비했다. 도구·데이터·측정 방법은 받고, 실제 측정은 하지 않고 방법과 자료를 이슈로 남기게 했다. 측정은 ISE-264, 화면 캡처(결제 거절 뒤 보상, Kafka-UI)는 ISE-265로 올렸다 — 근거: "실제 측정하지말고, 방법과 자료만 준비해서 이슈로 올려줘" (Claude Code)
- [수용] AI는 로그인 비밀번호·JWT 평문 전송을 HTTPS로 보완하자며 도메인 없이 Let's Encrypt IP 인증서(약 6일, certbot)를 붙이는 방법과 주의점(Grafana 링크 http 고정, HSTS 끔, 갱신 실패 알림)을 내고 진행 여부를 물었다. 11/16(월)에 붙이기로 하고 리마인드를 맡겼다. ISE-278로 올림. 같은 메시지로 머지한 PR 세 개(#580·#583·#597)의 브랜치 삭제도 확인함 — 근거: "브랜치 지워주고, https는 다음주 월요일날 달거야. 그때 리마인드해줘!" (Claude Code)
