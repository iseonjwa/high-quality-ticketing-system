# 2026-11-16 junhyun AI 판단 일지

- [수용] AI는 HTTPS(ISE-278)를 배포 두 번으로 나눠 붙이자고 했다. nginx 설정이 이미지에 들어 있고 인증서가 없는데 443 설정이 있으면 nginx가 뜨지 않으므로, 먼저 80에 인증서 발급 확인 경로를 배포하고(PR 1) 서버에서 certbot으로 받은 뒤 443을 배포한다(PR 2). frontend를 잠깐 내리는 standalone 방식은 서버에서 compose를 손으로 만지지 않는 규칙(`deploy-server-access.md` 4절) 때문에 권하지 않았다 — 근거: "응ㅇ 진행해줘!" (Claude Code)
- [선택] AI는 PR 663(인증서 발급 확인 경로)을 지금 dev에 머지하고 main에 올려 배포할지, 팀원 측정 확인 뒤에 할지 물었다. 지금 머지·배포를 골랐다. 배포 직전 발생기에 k6·컨테이너가 없고 배포 서버 측정 모드가 꺼진 것(발생기에서 9090 닫힘)을 읽기만 해서 확인했다 — 근거: 선택지 "지금 머지·배포" (Claude Code)
- [선택] 공유 설정(`compose.yml`)과 Grafana 주소가 바뀌어 팀 규칙대로 contract 이슈를 올리기로 하고, 담당은 배포 서버 측정(ISE-264) 담당인 영은으로 골랐다. ISE-290, 팀원 넷 멘션 — 근거: 선택지 "담당 영은" (Claude Code)
- [거부] AI가 design-system.md 1절에 정해 두고 화면 전체에 쓴 해요체 문구("좌석을 잡았어요", "결제 가능 시간이 지났거나 좌석이 풀렸어요")를 쓰지 않기로 했다. AI가 문구 종류별 예시 10개를 내고 사용자가 직접 고쳐 쓴 문장에서 규칙을 뽑는 방식으로 정했다. 서술은 합쇼체("완료되었습니다"), 요청은 "~해주세요", 잡다·풀리다·고르다 같은 구어는 선택·해제·반환 같은 단어로 바꾸고, 제목이 원인을 말하면 설명에서 원인을 되풀이하지 않는다. 버튼 문구는 그대로 둔다 — 근거: 사용자가 고쳐 쓴 예시 10개 (Claude Code)
- [수용] AI가 첫 묶음에서 뽑은 문체 규칙과 두 번째 묶음(규칙을 적용해 본 문구 10개)을 그대로 받았다. 요청은 "~해주시기 바랍니다" 없이 "~해주세요" 하나로, 제목은 마침표 없이, 설명 문장은 마침표로 끝낸다는 AI 기본안도 함께 받았다. 시연 데이터의 공연 소개 글은 이 문체를 쓰지 않고 공연마다 개성 있게 쓰며, 부적 화면은 별도 문체로 따로 정한다. ISE-292 — 근거: "이거 좋다. 이대로 가줘!" (Claude Code)
- [수용] 부적 화면(ISE-257)은 AI가 처음 쓴 해요체 문구("부적을 찾지 못했어요", "이미지를 길게 누르면 사진에 저장할 수 있어요")와 응원 문장 40개를 그대로 두기로 했다. 서비스 화면의 합쇼체(ISE-292)와 달리 이벤트 화면은 가벼운 말투가 맞다고 봤다 — 근거: "부적화면은 괜찮넹 그냥 이대로 하자" (Claude Code)
- [거부] AI가 PR 전에 목 모드 화면을 띄워 문구가 길어진 곳(좌석·결제·예매 상세)의 줄바꿈을 먼저 보자고 했으나 보지 않고 PR을 올리기로 했다. AI가 뜻을 짐작해 풀어 쓴 문구(로그인 카드 소개 세 줄, "당첨 및 결제가 완료되었습니다", "결제하신 수단으로 환불되었습니다", 운영자 화면의 장애 "적용/해제")도 그대로 받았다 — 근거: "아냐 괜찮아 이대로 pr 올려줘!" (Claude Code)
- [수용] AI가 의존성에 Swagger(springdoc)가 없고 SA의 "시연은 HTTP 요청 파일·Swagger"와 달리 붙이지 않았다고 알리며 붙일지 물었고, 붙이기로 했다. 붙이는 방식(서비스는 문서만, Gateway의 `/api/docs`에 화면 하나, 배포 nginx는 그대로)은 AI가 정했다. ISE-295, ADR 0063 — 근거: "스웨거도 해줘!" (Claude Code)
- [수용] AI가 Swagger(ISE-295) 구현 보고에서 배포 서버의 `/api/docs`가 로그인 없이 누구에게나 열린다(API를 부를 때 인증은 그대로)고 알렸고, 그대로 두고 셀프 리뷰가 끝나면 커밋·PR을 올리기로 했다 — 근거: "ㅇㅇ 끝나면 커밋하고 dev로 PR올려!" (Claude Code)
