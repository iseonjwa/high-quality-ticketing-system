# 역할 변경 확정: 결제 담당이 Mock PG까지 맡고 지원도 필요 없다고 해 SA·마일스톤의 Mock PG 담당과 결제 지원 계획을 고침

## 맥락
- 해결하려던 작업: 10/27 역할 변경(결제 전부는 안준현, 이강민은 User·공통 모듈 개선 뒤 추첨 기획·설계)을 문서에 반영한다(Linear ISE-48). 결제 담당 확정 답을 기다리고 있었다.
- AI 활용 방식: PR `#57`(결제 상세 설계) 리뷰를 요청했다.

## AI 제안
PR `#57` 리뷰 2번: 결제 설계 문서 8곳에 Mock PG 담당이 여전히 "이강민"이라 10/27 역할 변경과 어긋난다. Mock PG 담당 표기를 결제 담당으로 고치고, SA·milestones는 ISE-48에서 고친다.

## 판단
- 결과: 수용
- 판단자: kangmin (결제 담당 안준현의 확인을 전달)
- 근거: "준현님, 결제기능 일부 내가 지원하여 도와주려했던거 지원 필요없다 하셔서 다시 문서상 기능/역할 분담 정정해서 반영해줘"
- 검토한 대안: 10/27에 남긴 "도움 요청이 오면 지원한다"는 조건부 지원을 유지하는 안. 결제 담당이 지원 불필요를 확인해 뺐다.

## 반영
- `docs/core/SA MASTER.md`: 6-1 역할표(결제 행에 Mock PG 추가, 이강민 행을 "User·공통 → 추첨"으로), 6-6에 Mock PG 서버·장애 주입 행 이동, 6-7 제목·설명·MVP 행 교체(결제 재확인 스케줄러 공동 행 삭제), 6-9 결제 부담 미해결 항목 해소, 11장 Mock PG API 담당, 17-2 U16 담당, 부록 A C1 참조(6-7 → 6-6), 부록 C 변경 이력 1행
- `docs/core/milestones.md`: M2 담당 표, M3 아래 이강민 문단
- PR `#57`로 머지된 결제 문서의 Mock PG 담당 표기 9곳: ADR 0023(12·76·84행), `docs/design/payment/README.md`(의존 표의 이강민 행을 U9 확인만 남기고, Mock PG 일은 표 아래 문장으로 결제 담당 몫이라고 적음), `pg-integration.md`(19·71·74행), `failure-scenarios.md`(71행), `sa-change-requests.md`(S-28 협의 대상, 38행). 회의에서 말로 정리한 일이라 별도 요청 없이 ISE-48에서 같이 고치고 PR에서 결제 담당 확인을 받는다.
- 남은 것: Notion SA 정본. 10/28부터 변경을 모아 한 번에 반영하기로 해 반영 목록에 올렸다.

## 검증
문서 변경이라 빌드 대상이 아니다. `script/records-check.sh` 통과, SA·milestones에 Mock PG 담당이나 결제 지원으로 남은 "이강민" 표기가 이력 설명 말고는 없음을 grep으로 확인했다.

## 판단 이력
- 2026-10-27 결정 전달: 결제는 Mock PG 포함 안준현이 전부 맡고, 이강민은 도움 요청이 오면 지원한다([일지](daily/2026-10-27.md)).
- 2026-10-28 수용: 결제 담당이 지원도 필요 없다고 확인해 조건부 지원을 빼고 문서에 반영했다.
- 2026-10-28 선택: AI가 낸 두 안(결제 담당에게 정정 요청 / ISE-48에 포함) 중 ISE-48에 포함을 골랐다. 근거: "회의에서 말로 처리한 상황이니 지금 우리가 진행중인 이슈/PR에서 처리해서 올리도록하자". PR `#57` 리뷰 코멘트는 이미 머지돼 올리지 않는다.

## 발표·면접 포인트
- 담당을 바꿀 때 역할표 한 줄만이 아니라 API 담당, 미해결 항목, 일정 문서까지 같은 변경이 퍼져 있다. 한 이슈(ISE-48)로 묶어 빠짐없이 고쳤다.
