# 추첨을 다른 서비스와 같은 필수 기능으로 올려 기본 기능은 M2, 통합 테스트는 M3, 측정·개선은 M4에 둔다

## 맥락
- 해결하려던 작업: GitHub PR에 마일스톤을 붙이면서(ISE-141) 추첨 구현 PR을 Linear 이슈 마일스톤대로 M4에 배치했다.
- AI 활용 방식: Claude Code가 Linear 이슈의 마일스톤을 그대로 PR에 옮겼다. 재배치 요청을 받자 이 배치가 팀 문서(SA 4장 Should, 5-2 일정 M4, 6-7 "추첨 구현은 MVP 이후", `milestones.md` M4)에서 왔다는 근거를 보이고, 적용 범위(이슈·PR만 / 문서는 제안 / 문서까지 확정)를 물었다.

## AI 제안
- 추첨 구현 이슈와 PR을 기존 팀 문서대로 M4(고도화)에 둔다.
- 재배치는 팀 합의(추첨 = MVP 이후)를 바꾸는 일이므로, 이슈·PR만 옮기고 문서는 "제안(팀 확인 대기)"으로 올리자고 추천했다.

## 판단
- 결과: 거부 (M4 배치를 거부하고 재배치, 문서까지 확정)
- 판단자: 팀 (전달: 이강민)
- 근거: "추첨 기본 기능 구현 중인데 왜 M4인가. 다른 서비스와 동등하게 필수 기능으로 보고, 이후 통합 테스트와 수치 기반 개선·고도화를 M3·M4에 배치한다." 문서 반영 범위는 "팀 합의됨, 문서까지 확정"을 골랐다. 남은 기본 기능(종결·자동결제 요청·빌링키 자동결제)도 모두 M2로 두기로 했다.
