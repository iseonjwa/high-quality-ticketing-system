# AWS 담당 동의로 ISE-216(서버 추첨 생성 + k6 ID 전달)을 강민이 넘겨받아 처리하기로 함

## 맥락
- 해결하려던 작업: 배포 측정에서 L1~L3이 관리자 로그인 없이 돌게 하는 것. 운영 관리자 비밀번호는 발생기에 두지 않는다(ADR 0046 변경).
- AI 활용 방식: 1안(서버 `seed-demo.sh lottery`로 추첨을 만들고 k6는 `LOTTERY_ID`만 받기)을 제안받아 contract 이슈로 올리고, k6 쪽은 미리 구현했다.

## AI 제안
- 1안을 채택하고, `seed-demo.sh` 변경도 강민이 만들어 AWS 담당이 리뷰하게 한다.

## 판단
- 결과: 수용(팀원 결정 전달)
- 판단자: kangmin
- 근거: "준현님에게 허락받았어 내가 해당 이슈 넘겨받고 처리하자". AWS 담당의 동의는 Slack 등 저장소 밖에서 받았다. 세 가지 확인 항목에 각각 어떻게 답했는지는 이 기록 시점에 확인하지 못했다.
- 검토한 대안: 2안(측정 전용 관리자 계정을 발생기에 두기)

## 반영
- ISE-216 담당을 강민으로 바꾸고, `seed-demo.sh lottery`를 구현해 PR로 올린다. 진행 단계마다 사용자 확인을 받는다.

## 검증
진행 전이다. 완료 기준은 ISE-216 본문의 체크리스트다: 서버에서 추첨 id 출력, 발생기 L1 짧은 실행에서 `setup()` 통과.

## 판단 이력
- 2026-11-09 수용: AWS 담당 동의를 받아 이슈를 넘겨받았다.

## 발표·면접 포인트
- 권한이 필요한 준비는 비밀이 있는 곳(서버)에서 하고, 부하 발생기는 ID만 받는다. 비밀을 옮기지 않고 경계를 지키는 설계다.
