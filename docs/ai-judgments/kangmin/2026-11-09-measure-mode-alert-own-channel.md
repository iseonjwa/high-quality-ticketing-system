# 측정 모드 알림을 성능-모니터링 채널에 두지 않고 별도 채널로 옮기고, 배포 알림처럼 꾸미기로 함

## 맥락
- 해결하려던 작업: ISE-223으로 측정 모드 on/off 슬랙 알림을 붙였고, 11/9 서버 시험에서 `#이선좌-성능-모니터링`에 켬·끔 알림이 실제로 왔다.
- AI 활용 방식: 알림 채널 선택지(A 성능-모니터링 유지, B 배포상태알림, C 새 채널)를 비교받았다.

## AI 제안
- A를 추천했다. 측정 중 울리는 경보와 측정 모드 알림이 같은 채널에 있어 구분하기 쉽고, 새 웹훅이 필요 없다.
- C(새 채널)는 웹훅·`.env` 관리가 늘고 하루 몇 건짜리 알림이라 비추천했다.

## 판단
- 결과: 거부(C 선택)
- 판단자: kangmin
- 근거: "배포상태 알림이나 성능 모니터링처럼 좀 더 깔쌈하게 정리해서 메세지 보내려해 개선할 내용 정리해서 이슈화해보자 그리고 채널도 따로 추가하려해"
- 검토한 대안: A, B

## 반영
- 메시지 형식 개선(색 띠, 제목, 필드, 꼬리말)과 전용 채널을 후속 이슈로 정리한다. 시험 결과는 ISE-216·223에 남긴다.

## 검증
- 11/9 18:15 켬, 18:21 끔 알림이 `#이선좌-성능-모니터링`에 도착한 것을 슬랙 화면으로 확인했다(켜져 있던 시간 6분, 스모크 통과).

## 판단 이력
- 2026-11-09 거부: 전용 채널과 형식 개선을 골랐다.

## 발표·면접 포인트
- 알림은 "누가 어디서 보는가"로 채널을 나눈다. 측정 모드는 측정자들이 보는 운영 기록이라 장애 경보와 섞지 않기로 했다.
