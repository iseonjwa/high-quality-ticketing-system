# ISE-271에 PR AI 리뷰는 최소형 전부·위험 PR만 코멘트, 계약 경계 PR은 상대 확인·반나절 뒤 사후 확인으로 의견을 냄

## 맥락
- 해결하려던 작업: 인프라 담당이 연 ISE-271(남은 기간 PR마다 AI 리뷰를 남길지, 계약 경계 PR을 상대 담당이 볼지)에 11/14까지 찬반을 남겨야 했다.
- AI 활용 방식: Claude Code에 이슈 설명과 결정 근거, 대안을 요청했다. 근거로 11/12 dev 머지 PR 수(47개, 문서 17개)를 셌다.

## AI 제안
- 1번: 모든 PR은 최소형(본문 한 줄), 코멘트 게시는 경로·라벨로 정한 위험 PR만. 계약 경계·동시성 PR은 Claude와 codex 둘 다.
- 3번: 상대 담당 확인을 원칙으로 하되 반나절 안에 못 보면 CI 통과 뒤 머지하고 사후 확인. main 반영 전에는 확인이 끝나야 한다.
- 대안: 1번 A(지금처럼)·B(최소형만)·D(모든 PR 코멘트)·E(모든 PR 두 도구), 3번 A(먼저 머지)·B(승인 필수)·D(AI가 계약 문서와 대조). 각 안의 바꿀 조건. 상세는 `docs/learning/kangmin/qna/2026-11-14-ise271-ai-review-policy-options.md`.
