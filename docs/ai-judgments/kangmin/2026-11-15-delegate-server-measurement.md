# 서버 명령은 사람이 치고 AI는 명령표만 만든다는 방식을 바꿔 배포 서버 점검·측정을 AI에게 전부 맡기고 상황 보고를 이어서 받기로 함

## 맥락
- 해결하려던 작업: ISE-264 본 측정(약 100분, 무효면 155분), ISE-94 L2-b·시나리오 3, dev → main 뒤 재측정을 하루에 끝내기.
- AI 활용 방식: 오늘 계획에서 서버 트랙을 "강민이 SSH, 에이전트는 명령표·결과 정리"로 배치했다(11/14 인수인계 7절 "서버 명령(SSH)은 강민이 친다").

## AI 제안
서버 명령은 강민이 직접 치고, 에이전트는 명령표와 결과 정리만 한다. 그동안 로컬 문서 작업을 하위 세션이 병렬로 한다.
