# 0001. Java 21 사용

- 상태: 채택
- 날짜: 2026-10-26
- 결정자: Junhyun An
- 관련 AI 판단: [Java 25 대신 Java 21 선택](../ai-judgments/junhyun/2026-10-26-java-21.md)

## 맥락

SA MASTER v3 9-1은 Java 25를 기술 스택으로 적었다. Codex도 공통 모듈 구현 계획에 Java 25를 제안했다. 사용자는 "자바21버전으로 결정하자! SA도 수정하고"라고 지시했다.

## 결정

Java 21을 사용한다. 선택 이유는 미기재다. Junhyun An의 결정이며 팀 전체 합의를 뜻하지 않는다.

Notion SA 정본과 저장소 사본을 함께 수정한다. Spring Boot 4.1.x, Spring Cloud 2025.1.x, Gradle 9는 유지한다.

## 검토한 대안

- Java 25: 기존 SA와 AI 계획의 버전이다. 사용자가 Java 21로 변경했다.

## 결과

Gradle Toolchain, 컴파일 대상, 테스트, CI를 Java 21로 맞춘다. 기존 전역 Java 설정은 바꾸지 않는다.

Spring Boot 4.1.2는 Java 17 이상과 Gradle 9를 지원한다([공식 요구사항](https://docs.spring.io/spring-boot/system-requirements.html)). 실제 프로젝트 검증 결과는 [워크스페이스 가이드](../guides/workspace.md)에 남긴다.
