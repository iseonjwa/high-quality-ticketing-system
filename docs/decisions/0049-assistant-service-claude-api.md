# 0049. 내부 AI 상담은 별도 모듈 assistant-service로 두고, 벡터 DB 없이 키워드 검색 + Claude citations로 답하며, 키가 없거나 장애면 검색 모드로 강등한다

- 상태: 채택
- 날짜: 2026-11-09
- 결정자: 안준현(사용자 결정)
- 관련 AI 판단: [백로그 설계 결정](../ai-judgments/junhyun/2026-11-09-backlog-design-decisions.md)
- 관련 설계: [`design/assistant/README.md`](../design/assistant/README.md), SA MASTER F8(내부 AI 상담, Could)

## 맥락
- SA F8은 공연·예매 문의에 문서 검색 기반으로 답하고 출처를 보이는 상담이다. 예매·결제와 분리된 읽기 전용 모듈로 둔다. 발제의 "RAG 고객 응대 챗봇" 도전 과제에 해당한다.
- 형식과 백엔드는 담당(안준현)이 정한다. 11/13까지 다른 일이 많아 최소 범위로 가야 한다. 배포는 EC2 한 대라 메모리가 빠듯하다(컨테이너 상한 합계가 16GB급의 약 77%).
- Anthropic은 임베딩 모델을 제공하지 않는다. 벡터 검색을 하려면 다른 공급자의 키가 하나 더 필요하다.
- Gateway 전역 응답 시한은 3초다(SA 9-4). LLM 답변은 3초를 넘길 수 있다.

## 결정
1. 새 모듈 `assistant-service`로 둔다. DB·Redis·Kafka를 쓰지 않고 다른 서비스를 부르지 않는다. 상담이 죽어도 예매·결제에 영향이 없다.
2. 검색은 벡터 DB 없이 저장소 안 규정 문서(`knowledge/*.md`)의 키워드(한글 bigram) 점수로 상위 절을 고른다. 생성은 Claude API(`claude-haiku-5-5`, effort `low`)에 고른 절을 citations가 켜진 `document` 블록으로 넣어, 출처를 응답 citations에서 만든다.
3. `ANTHROPIC_API_KEY`가 없거나, LLM이 시한 초과·429·5xx·refusal·동시 호출 상한에 걸리면 오류 대신 200 `SEARCH`(검색 결과와 출처만)로 강등한다.
4. 상담 경로만 Gateway 응답 시한을 10초로 둔다(SA 9-4의 3초 상한 예외). SDK 시한은 8초, 재시도는 0회다.
5. 키는 `.env`에만 둔다. Anthropic에는 질문 원문만 보내고, 로그에는 질문 원문을 남기지 않는다.

## 검토한 대안
- **B. pgvector + 임베딩 RAG(Spring AI)**: 가장 전형적이다. 하지만 임베딩 공급자 키가 하나 더 필요하다. 벡터 DB 메모리(+512m)도 늘고, Spring AI가 Boot 4와 맞는지 확인이 필요하다. 구현량도 4~6일이라 금요일까지는 어렵다. 문서 묶음이 수천 토큰이라 벡터 검색의 이득이 작다.
- **C. LLM 없이 키워드 FAQ 검색만**: 하루면 된다. 하지만 검색(R)만 있어 RAG로 설명하기 약하다. 이 안은 결정 3의 강등 경로로 함께 만든다.
- **D. 기존 서비스(user 등)에 패키지로 넣기**: 모듈 추가(빌드·배포 9곳)가 없다. 하지만 로그인·재발급이 피크 경로라 LLM 대기 스레드와 외부 장애가 섞인다. SA의 "분리된 모듈"과도 어긋난다.
- **모델**: Sonnet 5.5·Opus 5.5는 품질이 높지만 질문당 비용이 20~40배다. 짧은 규정 답변과 8초 시한에는 Haiku 5.5로 시작하고, 골든 질문으로 확인한 뒤 필요하면 올린다. 모델은 설정값이다.

## 결과
- 키 없이도 기능이 동작한다(검색 모드). 그래서 일정 위험이 LLM 부분에만 남는다.
- 상담 경로만 10초 시한 예외가 생긴다. 다른 경로의 3초 규칙은 그대로다.
- 배포 컨테이너 상한 합계가 384m 늘어난다(`deployment.md`).
- 외부 의존(Anthropic API)과 비용이 생긴다. 질문당 약 $0.0005(가정). 사용자당·전체 일일 상한으로 막는다.
- 서비스 간 접점(Gateway 라우트, compose)이 바뀌어 contract 이슈로 알린다.

## 재검토 조건
- 문서가 수만 토큰 이상으로 늘거나 동적 데이터(공연·내 예매)를 넣게 되면 벡터 검색(B)과 서비스 간 조회를 다시 본다.
- 골든 질문에서 Haiku 5.5의 답 품질이 모자라면 모델을 올린다.
