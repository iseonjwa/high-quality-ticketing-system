# 학습 노트

팀원이 공부한 내용을 서로 공유하는 곳이다. 사람마다 폴더를 따로 둔다. 폴더 이름은 팀원 영문 이름이다. 처음 쓰는 팀원은 자기 폴더와 `README.md`를 만들고 아래 표에 한 줄을 추가한다.

## 규칙
- 자기 폴더만 고친다. 다른 사람의 노트에 의견이 있으면 PR 리뷰나 Notion에 남긴다.
- 처음에는 `qna/`(질문과 답)와 `README.md`(목록) 정도로 시작한다. `learning-note` 스킬이 이 형식으로 쓴다.
- 팀 공통 결정은 여기 두지 않는다. 결정은 `docs/decisions/`, AI 판단은 `docs/ai-judgments/<이름>/`, 문제 해결 기록은 `docs/troubleshooting.md`에 둔다.
- 사실과 추측을 구분하고, 확인하지 않은 내용은 "미확인"으로 적는다.
