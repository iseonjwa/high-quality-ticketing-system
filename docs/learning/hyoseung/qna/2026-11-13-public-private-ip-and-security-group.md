# 공인 IP·사설 IP와 보안 그룹

## 질문

IP는 내 컴퓨터에 붙은 번호라 장소가 바뀌어도 안 바뀌는 것 아닌가. 카페에서 배포 서버 SSH가 `Connection timed out`이 나는 이유는.

## 답

컴퓨터에 고정된 번호는 MAC 주소(네트워크 카드 고유 번호)다. IP는 붙어 있는 네트워크가 빌려주는 번호라 장소마다 바뀐다.

| | 누가 주나 | 장소를 옮기면 |
|---|---|---|
| 사설 IP(예: `192.168.0.12`) | 공유기가 안쪽 기기에 나눠 준다 | 바뀐다 |
| 공인 IP(예: `203.0.113.10`) | 인터넷 회사가 공유기에 준다. 같은 공유기 뒤 기기는 모두 이 IP로 나간다 | 공유기가 달라지니 바뀐다 |

- 서버가 보는 것은 공인 IP다. MAC 주소는 같은 공유기 안에서만 쓰이고 서버까지 가지 않는다.
- 배포 서버는 AWS 보안 그룹에 등록된 공인 IP에서 오는 SSH만 받는다. 등록되지 않은 IP는 응답 없이 버려져 `Connection timed out`이 난다(거절이 아니라 무응답).
- 지금 공인 IP는 `curl https://checkip.amazonaws.com`으로 보고, 보안 그룹 담당에게 `<IP>/32` 등록을 요청한다.
