# git worktree

## 질문

브랜치를 파는데 폴더가 왜 생기나. 브랜치가 폴더인가.

## 답

브랜치는 폴더가 아니다. 폴더는 `git worktree add <새 폴더> <브랜치>`로 따로 만든 것이다.

- 보통은 저장소 폴더 하나에서 `git switch`로 브랜치를 바꾸고, 같은 폴더의 파일이 그 브랜치 내용으로 바뀐다. 한 폴더에는 한 번에 한 브랜치만 열린다.
- worktree는 같은 저장소를 폴더로 하나 더 펼친 것이다. 커밋·브랜치 기록은 원래 폴더와 함께 쓰고 파일만 따로 있어, 두 브랜치를 동시에 열어 둘 수 있다. 그 폴더에서 커밋·push한 것은 원래 저장소에 그대로 반영된다.
- 쓰는 경우: 측정 중인 코드(Docker)를 건드리지 않고 다른 브랜치를 고칠 때, 커밋하지 않은 파일이 많은 폴더에서 브랜치를 바꾸기 곤란할 때.
- 주의: worktree로 파일을 복사해 올리면 원래 폴더의 파일은 그대로 남는다. 원래 폴더에서 `git pull`하면 같은 경로의 미추적 파일 때문에 멈추므로, 올라간 것과 같은지 확인하고 원래 폴더 사본을 지운 뒤 받는다.
- 다 쓴 폴더는 `git worktree remove <폴더>`로 지운다. 저장소 기록은 남는다. `git worktree list`로 목록을 본다.
