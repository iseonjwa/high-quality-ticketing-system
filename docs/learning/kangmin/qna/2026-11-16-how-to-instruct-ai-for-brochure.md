# AI에게 브로셔 작업을 시키는 법

- 날짜: 2026-11-16
- 질문: 브로셔를 하이퀄리티로 만들려면 AI에게 프롬프트를 어떻게 더 내려야 하나. "너였다면 너한테 어떻게 일을 시키겠어?"

## 답 요약
- 목표·독자·완료 기준을 먼저 고정한다. "예쁘게"가 아니라 "카드 크기에서 3초 안에 읽힘, 모든 숫자에 조건"처럼 확인할 수 있는 기준으로 쓴다.
- 사실 → 디자인 → 조립을 단계로 나누고 단계마다 확인 지점을 둔다.
- 숫자는 한곳(사실 원장)에만 두고 지시문에서는 id로 가리킨다. 옮겨 적다 틀리는 것을 막는다.
- 역할을 나눈다: 조사(Sonnet), 그림 시안(모델 둘 비교), 지휘(메인), 심사위원(만든 쪽과 다른 모델).
- 만든 에이전트가 스스로 검수하면 자기 전제를 의심하지 못한다. 새 맥락의 심사위원에게 결과물과 원문만 주고 채점표로 점수를 받는다. 미달이면 고쳐 다시 심사한다.

## 비교
| 방식 | 장점 | 대가 |
|---|---|---|
| 한 번에 전부 맡김 | 빠르다 | 숫자 과장·서사 붕괴를 끝에서야 안다 |
| 단계 + 심사 고리 | 빈틈을 일찍 찾는다 | 에이전트 비용과 시간이 더 든다 |
