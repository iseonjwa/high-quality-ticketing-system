# 발표 자료

최종 발표와 시연에 쓸 스크린샷, 이미지, 아이콘 같은 파일을 모은다. 발표 대표 사례의 글은 [`ai-judgments/`](../ai-judgments/README.md)(발표 후보), 설계 그림은 각 설계 문서에 있고, 여기에는 그 글에 붙일 그림 파일을 둔다.

- 파일 이름은 `YYYY-MM-DD-<내용>.<확장자>`다. 원본(SVG 등)이 있으면 같은 이름으로 함께 둔다.
- 비밀값이 보이는 화면(토큰, 웹훅 주소, `.env`, 실제 비밀번호)은 가린 뒤 올린다.
- 한 파일이 수 MB를 넘으면 줄여서 올린다.
