# 브로셔 디자인 규칙 (design-kit)

모든 브로셔 그림(메인 큰 그림, 카드 썸네일, 하이라이트, 하위 페이지 머리 그림)은 이 규칙을 따른다. 그림을 그리는 에이전트가 바뀌어도 한 벌로 보이게 하는 것이 목적이다. 기준 그림: 커버 배너 `2026-11-16-cover-banner.png`.

## 1. 캔버스

| 종류 | 크기(px) | 비율 | 안전 영역(핵심 요소) | 쓰는 곳 |
|---|---|---|---|---|
| 커버·카드 썸네일 | 1500×688 | 약 2.18:1 | 가장자리에서 가로 120·세로 80 안쪽 | Notion 갤러리 카드, 페이지 커버 |
| 메인 큰 그림 | 1600×900 | 16:9 | 가장자리 64 안쪽 | 숫자로 보는 이선좌, 화면 흐름, 하이라이트, 인포그래픽 |
| 하위 페이지 머리 그림 | 1600×600 | 8:3 | 가장자리 64 안쪽 | 하위 페이지 맨 위 |

- PNG는 2배(`--force-device-scale-factor=2`)로 저장한다. 원본 SVG를 함께 둔다.
- 카드 썸네일은 실제 크기(약 318×146)로 줄였을 때 큰 숫자·제목이 읽혀야 한다. 축소 미리보기를 함께 만든다.

## 2. 색 (프론트 디자인 시스템 토큰에서)

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| 주 색 | `#3B3BD4` | 바탕(어두운 그림), 강조 글자(밝은 그림) |
| 주 색 짙음 | `#24248F` | 바탕 그라데이션 아래쪽 |
| 강조(주황) | `#F59F00` | 핵심어 한 단어, 큰 배수 숫자. 작은 글자에는 쓰지 않는다(인디고 위 대비 3.56:1) |
| 성공(초록) | `#2B8A3E`, 밝은 판 `#63E6BE` | 0건·달성·자동결제 완료 |
| 경고(빨강) | `#E03131` | 개선 전 값, 미달 |
| 개선 전 회색 | `#C9CDD6` | 전후 막대의 "전" |
| 글자 | 흰 `#FFFFFF`(어두운 바탕), `#14161E`·`#373B4A`·`#676C7E`(밝은 바탕) |
| 밝은 바탕 | `#FBFBFD`, 카드 `#FFFFFF`, 테두리 `#E1E4EA` |

- 서비스별 강조색(카드 썸네일 숫자색): Gateway `#F59F00`, 대기열 `#74C0FC`, 좌석 `#FF8787`, 결제 `#63E6BE`, 추첨 `#FFD43B`, 인프라 `#B197FC`, AI `#FFA94D`, 팀 `#A9E34B`.

## 3. 글자

- 글꼴: Pretendard(없으면 Noto Sans KR). 굵기 900(큰 숫자·제목), 800(이름표·배지), 600(본문).
- 크기 위계(1600 폭 기준): 큰 배수 숫자 140~180, 제목 64~80, 부제 32~36, 조건 작은 글씨 20~22(어두운 바탕에서 흰색 70%).
- 한국어 문구만. 영문은 고유명사(Gateway, Kafka 등)만.
- 문체: 제목은 명사형·짧게("응답 6.6배 빠르게"), 조건 줄은 "조건: 초당 2,000건 · 상한 64 · 1회 측정"처럼 가운뎃점으로.

## 4. 숫자 표기 (정직성)

- 숫자는 `census/LEDGER.md`의 값만 쓰고, 그림 SVG 주석에 원장 id를 적는다.
- 큰 숫자 옆에는 반드시 조건 작은 글씨를 둔다(부하·회수·장비·날짜 중 해당하는 것).
- 배수는 "6.6배 빠르게", 감소는 "15배 줄임" 또는 "−85%", 없어진 것은 "0건". 반올림은 원장 값 그대로.
- 로컬 측정·계산값·시연은 조건 줄에 "로컬", "계산값", "시연 1건"을 쓴다.

## 5. 부품

| 부품 | 모양 |
|---|---|
| KPI 타일 | 둥근 사각형(모서리 24), 큰 숫자 + 한 줄 설명 + 조건 작은 글씨 |
| 전후 막대 | 0에서 시작, 같은 칸 안 같은 기준. 전 회색, 후 주 색 또는 서비스색. 막대 위에 값 |
| 배지 | 알약 모양(높이 66, 모서리 33), 체크 아이콘 + 굵은 문구 |
| 이름표 칩 | 흰 알약 + 주 색 글자 |
| 휴대폰 목업 | 검은 틀(모서리 34), 흰 화면(모서리 24), 필요한 정보 아래에서 끊음 |
| 무대 조명 | 위에서 퍼지는 흰 빛줄기(투명 20% → 0) |

## 6. 금지

- 그림자·그라데이션 남용(바탕 그라데이션 1개만), 이모지, 브랜드 로고 흉내(로고가 필요하면 Simple Icons 경로).
- 숫자 반올림·새 숫자·원장에 없는 숫자.
- 글자 겹침·가장자리 잘림. 끝나면 실제 크기 미리보기를 직접 열어 확인한다.
