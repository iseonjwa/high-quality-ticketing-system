# 주요 고려점

설계와 구현에서 고민한 지점을 발표 한 장씩으로 정리한다. 무엇을 골랐는지보다 왜 골랐고 무엇을 포기했는지가 보이게 쓴다. 정본은 [`decisions/`](../../decisions/README.md)의 ADR이다.

## 한 장 틀

고려점 하나에 파일 하나(`YYYY-MM-DD-<주제>.md`)를 두고 아래 순서로 쓴다. 그림이 있으면 같은 이름으로 함께 둔다.

1. 문제: 무엇이 어려웠는지. 가능하면 수치로 쓴다.
2. 선택지: 검토한 방법과 각각의 대가.
3. 선택과 이유: 고른 방법, 포기한 것.
4. 결과: 측정 수치, 테스트 결과. 아직 없으면 "미측정"으로 둔다.
5. 근거: ADR, 설계 문서, 측정 기록 링크.
