# 2026-11-06 리허설 실행 기록

아직 실행 결과가 없다. 실행한 시나리오만 아래 표에 한 줄씩 더한다. 시연 장면(P·A·D·F·L 번호)의 결과는 [시연 시나리오](../../design/demo/2026-11-06-mvp-scenarios.md) 5절에 쓰고, 여기에는 그 밖의 시나리오 ID를 쓴다.

| 항목 | 값 |
|---|---|
| 커밋 | 미기재 |
| 환경 | 미기재(로컬 또는 서버) |
| 실행자 | 미기재 |

| ID | 결과 | 실행 명령 또는 화면 | 근거(응답, traceId, 로그) | 비고 |
|---|---|---|---|---|

결과는 통과, 실패, 보류 중 하나로 쓴다. 통과에는 실행 명령과 결과를 함께 적는다. 실패하면 원인을 적거나 "원인: 미확인"으로 쓰고, 고친 뒤에는 행을 덮어쓰지 않고 새 행을 더한다.

새 회차는 이 파일을 복사해 `YYYY-MM-DD-<내용>.md`로 만든다.
